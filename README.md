# CarTrack

Smart professional car maintenance and expense tracker — Flutter frontend UI shell.

## Run

```bash
flutter pub get
flutter run
```

## Screens (UI only)

- **Dashboard** — vehicle overview, quick metrics, upcoming care, recent expenses
- **Reports** — spend overview, monthly bars, category breakdown, insights
- **Settings** — profile, vehicles, preferences, data & support

No backend or persistence yet; all data is static mock content.
